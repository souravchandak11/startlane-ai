# ESU video kit (Remotion)

Short-form video compositions for Euro Soccer USA, 1080x1920 @ 30fps.

## Compositions

| ID | Script | Length |
|---|---|---|
| `ESU-Script01-TooLate` | Script 1, "He's 10. Never played. Too late?" | 23s |

## Render

```bash
cd esu-video
npm install
npx remotion render src/index.ts ESU-Script01-TooLate out/ESU_S01_TooLate_NoMusic_1080x1920.mp4 --codec=h264 --crf=17
# then cap the true peak at -1 dBFS:
ffmpeg -i out/raw.mp4 -c:v copy -af "alimiter=limit=0.891:level=false" -c:a aac -b:a 320k out/final.mp4
```

Preview with `npx remotion studio`. If Remotion can't download its own Chrome, pass `--browser-executable` pointing at a local Chromium headless shell.

## Assets

- `public/audio/vo1.wav`, `vo2.wav`: Coach Denver's real on-camera audio from the @eurosoccerusa "Is 9 too late?" reel (2.92–10.68s and 10.70–16.75s), recut into two contiguous chunks.
- `public/footage/*.mp4`: clean crops from published @eurosoccerusa reels, positioned to avoid the graphics burned into those reels.
- `public/audio/{boom,whoosh,pop,tick,stamp,ding}.wav`, `public/img/grain.png`, and `src/data/voEnvelope.json` are generated by `scripts/prep_assets.py`.
- Exported without music (`_NoMusic`); add a commercial-library track at upload.
