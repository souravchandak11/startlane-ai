# Euro Soccer USA: AEO Specialist Hiring Kit

| File | Use it for |
|------|-----------|
| `01-linkedin-post.md` | The LinkedIn job post (copy and paste ready). |
| `02-candidate-questionnaire.md` | Send to every applicant **before** booking a call. |
| `03-screening-scorecard.md` | Internal only. Knockout checks, weighted scoring, red/green flags, call questions, trial task. |
| `04-outreach-messages.md` | DM / email templates for sending the questionnaire, follow-ups, and declines. |

**Budget:** ₹25,000 to ₹30,000 per month.

**Flow:** LinkedIn post → applicant comments/DMs → send questionnaire (04, message 1) → score with scorecard (03) → book a 30-min call only for 75+ (or 60+ if the pool is thin) → optional paid trial → offer.
