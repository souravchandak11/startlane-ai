# AEO Specialist Hiring Kit

The client stays anonymous until a candidate signs an NDA in Round 2. This repo is **public**, so:
- never add the client's name, website, locations or internal notes here
- keep the internal scorecard and answer key in a private place (Drive / Notion), not in this repo

| File | Who sees it | When |
|------|-------------|------|
| `01-linkedin-post.md` | Public | Job post |
| `02-round-1-questionnaire.md` | Shortlisted applicants | Before any call |
| `03-round-2-audit-brief.md` | Final 2–3 candidates | After screening call + signed NDA |
| `04-outreach-messages.md` | Internal templates | Throughout |

## Process

1. **LinkedIn post** (client unnamed). Applicants comment or DM.
2. **Quick shortlist** from the DM: one AEO win with numbers and a portfolio link.
3. **Round 1 questionnaire.** AEO skill, US youth soccer market knowledge, and a hands-on AI-search scan of a US metro.
4. **Score privately** with the internal scorecard.
5. **30-minute screening call** for the top 4–6.
6. **NDA, then Round 2 paid mini-audit** (4–5 hours, capped) for the final 2–3. This is where the client is revealed.
7. **Audit presentation call** (30 minutes).
8. **Offer**, with a 60-day probation tied to agreed KPIs.

**Budget:** ₹25,000 to ₹30,000 per month.
